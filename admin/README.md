# RK Printers - Admin Panel (React + Vite)

Standalone React + Vite admin dashboard and management system for RK Printers.

## Features
- **Dashboard**: Real-time sales metrics, leads count, revenue charts, order statistics.
- **Sales**:
  - Leads management (`/admin/leads`)
  - Customers management (`/admin/customers`)
  - Quotations generator & tracking (`/admin/quotations`)
  - Orders tracking & lifecycle (`/admin/orders`)
- **Catalogue**:
  - Catalogue Hub (`/admin/catalogue`)
  - Industries management (`/admin/industries`)
  - Categories (`/admin/categories`)
  - Products & variants (`/admin/products`)
  - Services (`/admin/services`)
  - Bulk Import (`/admin/bulk-import`)
  - Bulk Images (`/admin/bulk-images`)
  - Media Library (`/admin/media-library`)
  - Import History (`/admin/import-history`)
- **Operations**:
  - Inventory tracking (`/admin/inventory`)
  - Payments & transactions (`/admin/payments`)
  - Delivery & logistics (`/admin/delivery`)
- **Content**:
  - Portfolio items (`/admin/portfolio`)
  - Customer reviews & approvals (`/admin/reviews`)
  - Offers & promo codes (`/admin/offers`)
  - Blog & CMS (`/admin/blog`)
- **System**:
  - Store settings & preferences (`/admin/settings`)
  - Authentication (Login, Forgot Password, Reset Password)

## Getting Started

### Development
```bash
npm install
npm run dev
```
Runs at `http://localhost:5174`

### Production Build
```bash
npm run build
```
Builds the static application to `dist/`.
